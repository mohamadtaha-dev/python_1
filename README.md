## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mohamadtaha-dev/python_1.git
cd python_1
```

### 2. Install dependencies

Install the libraries required by the project:

```bash
pip install pandas scikit-learn
```

If the project uses additional libraries, install them before running the application.

### 3. Run the application

Navigate to the directory containing the Python entry-point file, then run:

```bash
python main.py
```

Use the actual entry-point filename if it differs from `main.py`.
